# 프로젝트: 운동피질 동역학 재현 + 인터랙티브 웹 시각화

## 목적
운동피질 집단 동역학의 두 고전적 결과를 재현하고, 동역학을 **직접 볼 수 있는**
인터랙티브·공유 가능한 웹 시각화를 만든다. 이 프로젝트는 **구현 + 학습**을 위한 것이다.
사소하지 않은 모든 설계 선택에 대해, `NOTES.md`와 코드 주석에 **왜 이 선택을 했고 무엇을
버렸는지**를 설명한다.

- **1단계 (기술적/descriptive):** 실제 M1 데이터에 PCA + jPCA → 회전 동역학
  (Churchland et al. 2012, Nature 487:51-56)
- **2단계 (기전적/mechanistic):** 과제로 학습한 RNN의 고정점 분석 → 그 회전을 **생성하는**
  국소 구조 (Sussillo & Barak 2013, Neural Computation 25(3):626-649;
  Sussillo et al. 2015, Nat Neurosci 18(7):1025-1033)

**전 과정에서 지켜야 할 개념적 관계:**
- jPCA는 **기술적(DESCRIPTIVE)**이다. 궤적 기하에 하나의 전역 선형계를 적합한다.
  방정식이 필요 없다. **뇌 데이터와 RNN 은닉 상태 둘 다**에 적용된다.
- 고정점 분석은 **기전적(MECHANISTIC)**이다. 시스템의 방정식이 필요하므로 **RNN에만**
  적용된다(우리는 뇌의 방정식을 갖고 있지 않다).
- 고정점이 jPCA가 **기술하는** 회전을 **생성한다**. 하나가 다른 하나를 설명하는 것이지,
  둘을 "서로 비교"하는 것이 아니다.
- 따라서: **뇌 = 궤적 + jPCA 평면만**(고정점 없음). **RNN = 궤적 + jPCA + 고정점 + 흐름장.**
  뷰어는 이 **비대칭을 반드시 드러내야** 한다.

  (오르빗 내장) + ipywidgets 슬라이더로 즉각적인 인라인 피드백을 준다. 결과를 `/data/*.json`으로
  내보낸다. 모든 절을 다음 구조로 구성한다: **(1)** 수학과 "왜"를 담은 markdown 셀,
  **(2)** 구현 코드 셀, **(3)** 결과를 즉시 보는 인라인 plotly 셀, **(4)** 해석 + 관찰된
  실패 모드 markdown 셀. **첫 셀:** Google Drive를 마운트하고 MC_Maze + 학습 가중치를 거기
  캐시한다(Colab 파일시스템은 휘발성이라 세션마다 재다운로드/재학습하지 않도록).

- **정적 웹앱 = 접시(plate).** React + Vite + react-three-fiber. 내보낸 JSON을 로드해
  Three.js로 렌더링한다. 실시간 계산 없음, 서버 없음, 브라우저 저장소 없음.
  ML 커뮤니티 발견성을 위해 공유 가능한 URL로 **Hugging Face Spaces (Static SDK)**에 배포한다.
  (GitHub Pages도 허용되는 대체안.)

**근거:** Colab의 인터랙티브 출력은 세션과 함께 사라지고 공유 링크가 되지 못한다. 개발 중에는
plotly가 "지금 바로 보기" 루프를 주고, Three.js가 배포 가능한 산출물을 준다. plotly 버전을
먼저 만들고, 시간이 남으면 Three.js로 올린다.

## 차등 검증 정책 (중요 — 직접 짠 코드를 반증 가능하게 만드는 방법)
두 어려운 알고리즘은 **직접(BY HAND)** 구현을 기본 경로로 하되, **동일 입력**에서 유지·관리되는
레퍼런스와 대조 검증한다. 레퍼런스는 대체재가 아니라 **기준(oracle)**이다. 직접 구현과 레퍼런스가
허용오차를 넘어 불일치하면 둘 중 하나가 틀린 것이다 — 진행 전에 디버그하라. **둘 다 코드에
남겨둔다**; 레퍼런스를 주석 처리하지 말 것.

- **jPCA 레퍼런스:** Benjamin Antin의 `jPCA` 파이썬 패키지(pip).
  일치 검증: 직접 구한 jPC 평면과 레퍼런스 평면 사이 **주각(principal angle) < 5도**;
  복원된 회전 주파수가 **5% 이내** 일치.
- **고정점 레퍼런스:** Sussillo & Barak의 경량 PyTorch 구현
  (예: `tripdancer0916/pytorch-fixed-point-analysis`). TensorFlow FixedPointFinder는
  **끌어오지 말 것** — PyTorch 스택과 충돌한다.
  일치 검증: 플립플롭에서 양쪽 모두 큐브 꼭짓점 근처 **8개 안정 고정점**을 찾는다;
  도달 RNN에서 헝가리안 정렬 후 고정점 집합이 허용오차 내 일치.

## 데이터
- **주 데이터:** MC_Maze (Neural Latents Benchmark '21, Pei et al. 2021), nlb_tools 경유.
  움직임 개시(movement onset)에 정렬. 준비(prep) + 움직임(movement) 구간 사용. 20 ms 빈,
  가우시안 스무딩 σ=40 ms, 발화율 소프트 정규화(Churchland 방식: rate/(range+5)).
- **MC_Maze 접근이 실패하면** 명시적으로 보고하고 대체 **공개(PUBLIC)** 도달 데이터셋을 제안한다.
  **합성 데이터로 대체하지 말 것** — 재현이 무의미해진다.

## 파이프라인 (구현 순서 = 마일스톤, 각각 반증 가능한 합격/불합격)

### M0. jPCA 직접 구현 (문장 단위 스펙)
1. 조건별 조건평균 발화율 `X_c(t)`를 취한다.
2. 각 뉴런을 소프트 정규화; 각 시점에서 조건간 평균(cross-condition mean)을 뺀다
   (이는 Lebedev et al. 2019가 비판한 단계 — NOTES에 기록하고, 충실한 재현을 위해 유지하며,
   전/후 비교를 저장한다).
3. 스택된 전처리 데이터에 PCA; 상위 k=6 PC 유지. 투영해 `X`(k차원)를 얻는다.
4. 유한차분으로 상태 도함수 `Ẋ`를 계산한다.
5. `M`이 **반대칭(skew-symmetric, M = -Mᵀ)**이라는 제약 하에 `Ẋ = M X`를 적합한다:
   벡터화하여 제약 최소제곱을 **닫힌 형태로** 푼다(이것이 크럭스 — 제약을 정확히,
   Churchland 2012 보충 방법 인용).
6. `M`을 고유분해; 고유값은 순허수(±iω 쌍). `|ω|`가 가장 큰 쌍이 최상위 jPC 평면을 정의한다.
7. 궤적을 jPC 평면에 투영; 회전을 그려야 한다.
**합격/불합격:** `Ẋ=MX`의 적합 R² 보고; 최상위 회전 평면 분산 비율 보고; Antin `jPCA` 대비
차등 검증 통과.

### M1. 기기 보정: 플립플롭 (정답이 알려짐) — 이것부터 하라
- 작은 바닐라 tanh RNN을 3-bit 플립플롭 과제로 학습(Sussillo & Barak 2013).
- `fixedpoints.py` 실행.
- **반증 검사:** 상태 공간에서 큐브 꼭짓점 근처에 위치한 **정확히 8개의 안정 고정점**.
  아니면 도달 데이터를 건드리기 전에 **멈추고** 탐색기를 디버그하라.
- 이 8개 고정점 + 궤적을 최소 뷰어에 렌더링(정답을 아는 사례에서 시각화 파이프라인도 검증).

### M2. 뇌 데이터: PCA + jPCA (1단계)
- M0 파이프라인을 MC_Maze에 적용.
- 뇌 뷰어: 조건별 궤적 + 강조된 jPCA 회전 평면. **고정점 없음(방정식 없음).**

### M3. 도달 RNN + jPCA (2단계, 1부)
- **핵심 개념(NOTES에 명시):** RNN은 **행동 과제(BEHAVIORAL TASK)**로 학습하지, 신경
  데이터로 학습하지 않는다. 입력 = 목표/조건 큐 + go 신호. 출력 = 손 속도(또는 EMG). 그런 다음
  **창발한(EMERGENT)** 은닉 동역학이 M1과 닮았는지 묻는다. (이것이 Sussillo et al. 2015의
  방법이다; "RNN을 스파이크에 적합"과 혼동하는 것이 고전적 치명적 오해다.)
- **RNN 스펙:** 256 유닛, tanh, 연속시간 `dx/dt = -x + W_rec·φ(x) + W_in·u + b`,
  `z = W_out·x`. 대사(metabolic) 정규화(발화율 L2)는 **필수** — 없으면 네트워크가 비생물학적
  고차원 해를 찾는다.
- **합격/불합격:** 과제 성능(속도 R²)을 보고하고, **어떤 동역학 분석보다 먼저** 임계값 이상을
  요구한다(과제에 실패한 네트워크를 분석하는 것은 무의미).
- 같은 PCA/jPCA를 은닉 상태에 적용 → RNN도 회전하는가?

### M4. 도달 RNN 고정점 + 흐름장 (2단계, 2부)
- `fixedpoints.py`: `q(x) = ½‖dx/dt‖²` 최소화. 옵티마이저: Adam 후 선택적 L-BFGS 다듬기.
  초기조건은 **실제 시행에서 방문한 은닉 상태(+작은 노이즈)에서만** 샘플링 — 균일 샘플링은
  허위 저속점을 낳는다.
- 저속점 허용; 허용오차는 **q 값들의 분포**에서 정하고, 절대 임계값을 하드코딩하지 말 것
  (네트워크 의존적). 인접 최소점은 군집화로 중복 제거.
- 각 점을 야코비안 `J = ∂(dx/dt)/∂x` 고유값으로 분류: 안정/불안정/안장/회전
  (실수부가 0에 가까운 복소쌍).
- `flowfield.py`: 최상위 PCA 평면 격자 위의 dx/dt.
- RNN 뷰어: 궤적 + 흐름장 + 안정성 분류별로 색칠한 고정점.

### M5. 통합 뷰어 + 배포
- 토글: 뇌 | RNN | 나란히. 주의: 둘은 **서로 다른 공간**에 산다; 각각을 자기 jPCA 공간에서
  렌더링하고 **시각적 스케일만** 맞춘다 — 하나의 좌표계로 억지로 밀어넣지 말 것. 뷰어는 이
  한계를 정직하게 드러내야 한다.
- 정적 앱을 Hugging Face Spaces (Static SDK)에 배포.

## 인터랙티브 시각화 스펙 (일급 산출물 — 여기 투자하라)
**필수 상호작용:**
- OrbitControls (회전/줌/팬).
- 시간 스크러버 + 재생/일시정지: 궤적이 시간에 따라 그려짐.
- 조건 선택기: 개별 도달 조건 표시/숨김.
- 뷰 토글: 뇌(M1) | RNN | 나란히.
- RNN 전용: 흐름장 토글; 고정점 토글; 고정점 호버 시 툴팁이 야코비안 고유값 + 안정성 분류 표시.
- jPCA 회전 평면 강조 토글.

**표현:**
- 궤적은 매끄러운 TubeGeometry, 조건은 색상(hue)으로 구분.
- 고정점은 안정성 분류별 색상.

**미학(애플급, 절제):** 어두운 배경, 은은한 격자, 높은 대비, 깔끔한 타이포그래피 축 레이블/범례.
불필요한 효과 없음. 뇌와 RNN을 **일치된 시각 스케일**로 렌더링해 차이가 눈에 보이게 한다.

**JSON 스키마(예시):**
```json
{ "trajectories": {"cond_id": [[x,y,z], ...]},
  "fixed_points": [{"pos":[x,y,z], "eigs":[[re,im],...], "stability":"saddle"}],
  "flow_field": [{"pos":[x,y,z], "vec":[dx,dy,dz]}],
  "jpca_plane": [[...],[...]], "meta": {...} }
```

# 부록 A · 구현 현황 (M0–M5 전부 완료)

전 마일스톤이 반증 가능한 합격 기준을 실제 수치와 함께 통과했다. 자세한 근거·수치는
`NOTES.md`, 재현 실행은 `tests/test_m*.py`.

| 마일스톤 | 상태 | 핵심 수치 |
|---|---|---|
| **M0** jPCA 직접 구현 | 통과 | Antin 대비 주각 **0.0008°**, 주파수 **0.000%**; 두 닫힌형태 해 일치 9e-16 |
| **M1** 플립플롭 보정 | 통과 | task MSE **0.0083**; **정확히 8개** 안정 고정점 = 8 큐브 꼭짓점; 레퍼런스 일치 정밀도 5e-4 |
| **M2** 뇌 jPCA | 통과 | 적합 R² **0.524**, 평면분산 **0.464**, **1.37 Hz**; 실데이터 Antin 일치 0.0001° |
| **M3** 도달 RNN + jPCA | 통과 | 속도 R² **0.9989**; 은닉 상태 회전 적합 R² **0.884** (스파이크 없이 창발) |
| **M4** 고정점 + 흐름장 | 통과 | **회전 안장점 1개**, 주고유쌍 **0.51±1.33i**; IC 재샘플링 0.038, 독립 Newton 잔차 2.3e-7; 흐름 curl +0.96 |
| **M5** 통합 뷰어 | 완료·검증 | 자체완결 `web/index.html`(외부 라이브러리 0); Playwright로 렌더 확인, 콘솔 에러 없음 |

**핵심 결론:** M4의 복소 고유쌍(±1.33i)이 M2/M3에서 jPCA가 *기술*하던 회전을 *생성*한다 —
기술↔기전이 연결됨. 그리고 플립플롭 8개 점끌개 vs 도달 안장점 1개 = 같은 탐색기, 반대 위상,
계산이 다르기 때문.

**적대적 검증(정직하게):**
- M2(Lebedev): 조건간평균 차감 *없이도* 회전이 남음 → CCM이 회전을 만들어내지 않음.
  단 주파수는 1.37→2.49 Hz로 바뀜(무엇을 측정하는지가 달라짐).
- M4: IC 재샘플링·독립 Newton 솔버 양쪽으로 확인 → 인공물 아님.
